# Revistamento ZTO

App web (PWA) para a rotina do revistamento de vagões: distribuição dos trens entre as equipes, apontamento dos vagões
no celular, validação técnica e painel de indicadores. Uso interno; o acesso exige login e as regras de acesso ficam no servidor.

Abrir: https://mausan2013-dotcom.github.io/revistamento-zto/
